# EGOR // INFORMATICS TUTOR

Сайт-визитка репетитора по информатике в стиле Matrix.

## Что улучшено

- Убрана фраза «Ты готов войти в систему?» со стартовой заставки.
- Кнопка входа на заставке стала крупнее и получила аккуратный glitch-эффект.
- Добавлена полноценная адаптивная навигация с мобильным меню.
- Добавлен индикатор прогресса прокрутки и кнопка возврата наверх.
- Добавлены плавные появления блоков при скролле.
- Улучшены hover/focus/active-состояния и доступность клавиатурой.
- Matrix-анимация автоматически приостанавливается, когда вкладка скрыта.
- На мобильных отключены тяжёлые hover/parallax-эффекты.
- Учтён `prefers-reduced-motion`.
- Добавлен FAQ на нативных `details/summary`.
- Добавлен плавающий быстрый переход в Telegram.
- Улучшены SEO-метаданные и Open Graph.
- Фоновая картинка подключается напрямую из `matrix-bg.png`, поэтому комплект из этих файлов запускается без обязательной папки `assets`.

## Структура

- `index(2).html` — разметка
- `style(1).css` — стили, адаптив и анимации
- `script(1).js` — Matrix rain, меню, scroll UI, reveal-анимации и интерактив
- `matrix-bg.png` — фон

## Запуск

Положите 4 файла в одну папку и откройте HTML-файл в браузере. Для публикации папку можно разместить на Vercel или Netlify.
